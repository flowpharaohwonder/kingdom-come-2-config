## ✨ Features

### 🎮 Core Tweaks
- Performance Presets — low, medium, high, ultra profiles in one click
- HUD Tweaks — toggle compass, health bar, stamina, and quest markers
- Save Manager — backup, restore, and swap save slots safely
- Keybind Profiles — save and load custom control layouts
- Graphics Editor — adjust shadows, textures, and draw distance

### 🎨 Visual & Interface
- FOV Adjustment — set custom field of view beyond vanilla limits
- Photo Mode Unlock — remove camera restrictions for screenshots
- UI Scaling — resize menus and subtitles for any resolution
- Color Grading — apply cinematic or neutral LUT presets

### 🏋️ Quality of Life
- Auto-Save Interval — change frequency of automatic saves
- Weight Limit Presets — choose from balanced or unlimited carry options
- Combat Slowdown — tweak time dilation during fights
- Fast Travel Options — enable or disable map restrictions
